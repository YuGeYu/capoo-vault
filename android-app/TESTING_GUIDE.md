# 猫猫虫仓库 Android APP - 测试指南

## 快速测试步骤

### 方式一：使用 Android 模拟器（推荐用于快速验证）

#### 1. 启动模拟器
```bash
# 查看可用的模拟器
emulator -list-avds

# 启动模拟器（替换为你的模拟器名称）
emulator -avd Pixel_5_API_30 &
```

#### 2. 安装 APK
```bash
cd android-app
adb install dist/maomaochong-android-v1.0.0.apk
```

#### 3. 启动应用
在模拟器中找到"猫猫虫仓库"图标，点击启动。

#### 4. 测试下载功能（可选：使用本地测试服务器）
```bash
# 在 android-app 目录下已有 dl_test_server.py
python dl_test_server.py
```
然后在 APP 中访问 `http://10.0.2.2:8000` 测试下载功能。

---

### 方式二：使用真实 Android 设备

#### 1. 准备工作
- 在手机上启用"开发者选项"和"USB 调试"
- 通过 USB 连接手机到电脑

#### 2. 确认设备连接
```bash
adb devices
```
应该看到你的设备列出。

#### 3. 安装 APK
```bash
cd android-app
adb install dist/maomaochong-android-v1.0.0.apk
```

#### 4. 测试
在手机上找到并启动"猫猫虫仓库"应用。

---

### 方式三：手动安装（最终用户方式）

#### 1. 传输 APK
将 `android-app/dist/maomaochong-android-v1.0.0.apk` 复制到手机。

#### 2. 允许未知来源
- 打开手机设置
- 找到"安全" → "未知来源"
- 允许从文件管理器安装应用

#### 3. 安装
- 使用文件管理器找到 APK
- 点击安装
- 按提示完成安装

## 常见问题排查

### Q1: APK 无法安装
**症状**: 点击安装时提示"应用未安装"或"解析包时出现问题"

**可能原因**:
- APK 文件损坏
- 系统版本过低（需要 Android 6.0+）
- 签名问题

**解决方法**:
```bash
# 验证 APK 完整性
cd android-app
sha256sum dist/maomaochong-android-v1.0.0.apk
# 应该输出: a6e6cd4ea643f5a6c60d97382b03df589f02b2a5107688539577ea316e7c6c9d

# 检查 Android 版本
adb shell getprop ro.build.version.sdk
# 应该 >= 23 (Android 6.0)
```

### Q2: APP 无法打开或闪退
**症状**: 点击图标后 APP 立即关闭

**排查方法**:
```bash
# 查看崩溃日志
adb logcat | grep -i "crash\|exception"

# 或查看 APP 专属日志
adb logcat | grep "xyz.maomaochongmiao.app"
```

### Q3: 网页无法加载
**症状**: APP 打开后一片空白或显示错误页

**可能原因**:
- 网络未连接
- 网站服务器问题
- DNS 解析问题

**排查方法**:
```bash
# 测试网络连接
ping maomaochongmiao.600318.xyz

# 测试 HTTPS 访问
curl -I https://maomaochongmiao.600318.xyz/
```

### Q4: 文件下载无响应
**症状**: 点击下载按钮无反应，没有任何提示

**可能原因**:
- 下载权限被禁用
- DownloadManager 服务不可用
- 存储空间不足

**排查方法**:
```bash
# 检查下载管理器状态
adb shell dumpsys download

# 检查存储空间
adb shell df /sdcard
```

### Q5: 文件选择器打开失败
**症状**: 点击"选择文件"后提示"未找到可用的文件选择器"

**可能原因**:
- 系统没有文件管理器
- 文件管理器被禁用

**解决方法**:
- 从应用商店安装一个文件管理器（如"文件管理器"、"ES文件浏览器"等）
