- 新增一次性升级脚本：
  - `schema/007_redeem_code_products.sql`

线上旧库升级时需要先执行：

```bash
npm run db:migrate:remote:redeem-products
```

本地旧库升级时执行：

```bash
npm run db:migrate:local:redeem-products
```
