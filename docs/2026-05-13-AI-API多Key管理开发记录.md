# 2026-05-13 AI API 多 Key 管理开发记录

## 本次变更

- API Key 从每个用户 1 个扩展为普通用户最多 10 个、API 会员最多 100 个。
- 用户 API 页面新增 Key 列表管理：
  - 新增 Key
  - 重置单个 Key
  - 启用 / 禁用单个 Key
  - 保存备注
  - 复制本次新生成或重置后显示的完整 Key
- 调用方式示例改为 Python `requests`，用户侧不展示内部模型参数。
- 站长后台 AI API 用户列表改为显示 Key 总数、启用数量和最近调用时间，避免多 Key 后用户重复显示。

## 数据库变更

- `schema/005_ai_api.sql` 已调整为新安装时直接创建多 Key 结构。
- 新增 `schema/006_ai_api_multi_keys.sql`，用于已经部署过旧版 `005` 的线上库升级：
  - 去掉 `ai_api_keys.user_id` 的唯一约束。
  - 新增 `note` 字段。
  - 保留旧 Key 记录。
  - 新增 `idx_ai_api_keys_user_id` 索引。

线上旧库升级时需要单独执行：

```bash
npm run db:migrate:remote:ai-api-multi-keys
```

本地旧库升级时执行：

```bash
npm run db:migrate:local:ai-api-multi-keys
```
