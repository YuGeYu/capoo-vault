# 2026-05-13 AI API 开发者向开发记录

## 背景

本轮围绕猫猫虫咖波表情包仓库的 AI API 做了一次完整增强，目标是把 API 功能从“单 Key 申请 + 基础调用”升级为可长期运营的 API 服务入口。

核心原则：

- 用户侧不暴露内部模型路由。
- 调用方式尽量简单，只需要提交 `messages`。
- 计费、会员、余额、兑换码、Key 管理都在本站 Worker 内统一处理。
- 站长仍然保留手动充值余额、手动开通 / 续期 API 会员的后台能力。

## 本轮功能

### 1. 多 API Key 管理

普通用户最多可申请 10 个 API Key。

API 会员最多可申请 100 个 API Key。

用户可以在 `/tools/ai-api` 页面管理自己的 Key：

- 新增 Key
- 重置单个 Key
- 启用 / 禁用单个 Key
- 给 Key 保存备注
- 复制本次生成或重置后显示的完整 Key

完整 Key 只在生成或重置时显示一次，数据库只保存哈希和前缀。

### 2. API 会员与余额兑换码

新增三类 API 兑换码：

- `ai_api_member_monthly`：API会员月卡，￥6.00 / 30 天
- `ai_api_balance_1`：API余额 1 元
- `ai_api_balance_10`：API余额 10 元

用户在 `/tools/ai-api` 页面点击“购买兑换码”会新标签页打开：

```text
https://your-shop.example/product/ai-api-member
```

购买后回到页面填写兑换码。兑换成功后：

- API会员月卡会给当前账号续期 30 天。
- 1 元 / 10 元兑换码会充值到当前账号的 API 余额。

### 3. 站长后台补货

站长登录 `/dashboard` 后，可以在“兑换码补货”面板添加兑换码。

补货时可选择兑换码类型：

- 抠图会员月卡
- API会员月卡
- API余额 1 元
- API余额 10 元

兑换码规则：

- 一个兑换码只能使用一次。
- 使用后永久保留记录。
- 已存在的兑换码不会重复添加。

### 4. Python 调用示例与返回示例

API 页面已新增 Python 调用示例。

用户侧示例不再展示：

- `model`
- 内部模型名称
- 上游服务路由

用户只需要提交：

```json
{
  "messages": [
    { "role": "user", "content": "请用一句话介绍猫猫虫咖波表情包仓库的 AI API。" }
  ],
  "temperature": 0.7
}
```

页面同时新增返回示例，展示 `ok`、`reply`、`usage` 三个主要部分。

## 接口变更

### 用户 API Dashboard

```http
GET /api/dashboard/ai-api
```

返回内容新增：

- `keys`
- `limits`
- `redeem`

### 创建 Key

```http
POST /api/dashboard/ai-api/key
```

请求体：

```json
{
  "note": "Key 1"
}
```

### 更新 Key

```http
PATCH /api/dashboard/ai-api/key/:keyId
```

支持更新：

```json
{
  "note": "网站后端",
  "status": "active"
}
```

`status` 可为：

- `active`
- `disabled`

### 重置 Key

```http
POST /api/dashboard/ai-api/key/:keyId/reset
```

重置后旧 Key 立即失效，新 Key 只在响应中显示一次。

### 兑换 API 兑换码

```http
POST /api/dashboard/ai-api/redeem
```

请求体：

```json
{
  "code": "兑换码"
}
```

### 开放 API 调用

```http
POST /api/open/ai-chat
Authorization: Bearer mmc_xxx
Content-Type: application/json
```

请求体：

```json
{
  "messages": [
    { "role": "user", "content": "你好" }
  ],
  "temperature": 0.7
}
```

响应中已移除 `model` 字段，避免暴露内部模型路由。

## 数据库变更

### `schema/005_ai_api.sql`

新库创建时，`ai_api_keys` 已支持多 Key：

- `user_id` 不再唯一
- 新增 `note`
- 增加 `idx_ai_api_keys_user_id`

### `schema/006_ai_api_multi_keys.sql`

用于旧库升级：

```bash
npm run db:migrate:remote:ai-api-multi-keys
```

该脚本会保留旧 Key，并迁移为多 Key 结构。

### `schema/004_remove_bg_redeem_codes.sql`

新库创建时，兑换码表已支持产品类型：

- `product_code`
- `amount`
- `duration_days`

### `schema/007_redeem_code_products.sql`

用于旧库升级：

```bash
npm run db:migrate:remote:redeem-products
```
