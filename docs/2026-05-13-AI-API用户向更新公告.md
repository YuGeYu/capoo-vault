# AI 对话 API 功能更新公告

猫猫虫咖波表情包仓库的 AI 对话 API 功能已经更新。

这次更新主要面向想用程序、脚本、机器人或网页功能调用 AI 对话能力的用户。

入口：

```text
/tools/ai-api
```

## 新增 API Key 管理

现在每个账号可以管理多个 API Key。

普通用户最多可以申请 10 个 Key。

API 会员最多可以申请 100 个 Key。

每个 Key 都支持：

- 添加备注
- 禁用
- 重新启用
- 重置
- 复制新生成的完整 Key

完整 Key 只会在生成或重置时显示一次，请及时保存。不要把自己的 Key 发给别人。

## 新增 API 会员月卡

API会员月卡价格：

```text
￥6.00 / 30 天
```

API 会员权益：

- 每天前 500 次成功调用免费
- 超出免费额度后，按 ￥0.001 / 次从 API 余额扣费
- 可申请最多 100 个 API Key

普通用户权益：

- 每天前 50 次成功调用免费
- 超出免费额度后，按 ￥0.003 / 次从 API 余额扣费
- 可申请最多 10 个 API Key

只有 AI 正常返回内容，才算一次成功调用。

调用失败、Key 无效、余额不足、参数错误、上下文过长或 AI 服务异常，都不会扣费。

## 新增余额兑换码

现在支持购买并兑换：

- API会员月卡兑换码
- API余额 1 元兑换码
- API余额 10 元兑换码

购买入口会在新标签页打开店铺：

```text
https://pay.ldxp.cn/shop/lbtvjbtv
```

购买后回到 `/tools/ai-api` 页面，把兑换码填入兑换框即可。

兑换成功后：

- 会员月卡会自动增加 30 天 API 会员时长
- 1 元兑换码会增加 1 元 API 余额
- 10 元兑换码会增加 10 元 API 余额

每个兑换码只能使用一次。

## 调用方式更简单了

页面现在提供 Python 调用示例。

你不需要填写模型参数，也不需要了解本站内部如何选择 AI 服务。

只要传入消息内容即可。

示例：

```python
import requests

url = "https://maomaochongmiao.600318.xyz/api/open/ai-chat"
api_key = "你的_API_Key"

response = requests.post(
    url,
    headers={
        "Authorization": f"Bearer {api_key}",
        "Content-Type": "application/json",
    },
    json={
        "messages": [
            {"role": "user", "content": "请用一句话介绍猫猫虫咖波表情包仓库的 AI API。"}
        ],
        "temperature": 0.7,
    },
    timeout=60,
)

response.raise_for_status()
data = response.json()
print(data["reply"])
```
