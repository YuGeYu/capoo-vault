# AI 对话 API 申请工具上线公告

猫猫虫咖波表情包仓库新增了一个面向用户和开发者的小工具：

- AI 对话 API 申请

入口：

- 网站首页工具列表
- `/tools/ai-api`

## 这个工具能做什么

登录后，你可以在页面中申请一个属于自己的 API Key。

拿到 Key 后，就可以通过程序调用本站提供的 AI 对话 API 服务。你可以把它用于自己的小工具、脚本、机器人、网页功能或自动化流程。

本站会作为中转站调用 AI 服务，你不需要直接接触上游 AI 服务配置。

## 免费额度

普通用户：

- 每天前 50 次成功调用免费。
- 超过 50 次后，按 `0.003 元 / 次` 从余额中扣费。

API 调用会员：

- 每天前 500 次成功调用免费。
- 超过 500 次后，按 `0.001 元 / 次` 从余额中扣费。

API 调用会员建议价格：

- `6.00 元 / 30 天`

## 什么时候会扣费

只有 AI 正常返回内容，才算一次成功调用。

这些情况不会计入成功次数，也不会扣费：

- API Key 无效。
- 余额不足。
- 参数格式错误。
- 上下文太长导致失败。
- AI 服务暂时不可用。
- AI 服务超时或返回异常。

简单说：调用失败不算次数，也不扣余额。

## 关于上下文长度

调用 API 时，不建议一次性塞入太长的历史对话。

如果上下文太长，可能会调用失败。失败不会扣费，但会影响你的使用体验。

建议只提交必要的最近几轮对话，或者先把长内容压缩整理后再发送。

## 和站内 AI 聊天的区别

站内 AI 聊天页面：

- 入口是 `/tools/ai-chat`
- 默认会按猫猫虫仓库站内助手的方式回答
- 适合直接在网页里聊天、问站内功能、上传图片提问

AI 对话 API：

- 入口是 `/tools/ai-api`
- 正式调用接口是 `/api/open/ai-chat`
- 默认不会自动带网站 AI 聊天设定
- 如果你需要指定 AI 的身份、语气或任务，需要自己在请求中传入 system 消息

## 调用示例

```bash
curl https://maomaochongmiao.600318.xyz/api/open/ai-chat \
  -H "Authorization: Bearer 你的_API_Key" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "zhipu/glm-4-flash",
    "messages": [
      { "role": "user", "content": "你好，介绍一下你能做什么" }
    ],
    "temperature": 0.7
  }'
```

## 使用提醒

1. API Key 只会在生成或重置时完整显示一次，请及时保存。
2. 不要把自己的 API Key 发给别人。
3. 如果怀疑 Key 泄露，请立刻在页面里重置。
4. 当前充值由站长后台手动处理，后续可能接入更方便的在线充值方式。
5. 这个 API 适合轻量调用，不建议用来提交超长上下文或高频刷量任务。
