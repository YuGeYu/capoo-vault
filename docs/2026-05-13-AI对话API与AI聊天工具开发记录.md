# 2026-05-13 AI 对话 API 与 AI 聊天工具开发记录

## 本次目标

本次围绕站内 AI 能力做了两类扩展：

1. 新增面向普通用户的 AI 聊天工具页。
2. 新增面向开发者和外部程序调用的 AI 对话 API 申请与调用体系。

核心原则是：浏览器端不直接暴露上游 AI 服务密钥，所有正式调用统一由本站 Worker 作为中转层处理。

- `/tools/ai-chat`

新增前端模块：

- `public/ai-chat-tool.js`

- 抠图会员与兑换码。

### 2. AI 聊天 Worker 代理

新增内部工具接口：

- `POST /api/tools/ai-chat`

接口位置：

- `src/worker.js`

用途：

- 给站内 `/tools/ai-chat` 页面使用。
- 由 Worker 代理调用上游 AI 服务。
- 浏览器端不暴露上游 API Key。

当前上游地址：

- `https://platform.aitools.cfd/api/v1/chat/completions`

当前支持模型：

- `zhipu/glm-4-flash`
- `qwen/qwen3-8b`
- `qwen/qwen2.5-7b`
- `google/gemma-3-27b`

图片模型：

- `zhipu/glm-4v-flash`
- `zhipu/glm-4.1v-thinking-flash`
- `zhipu/glm-4.6v-flash`

### 3. AI 对话 API 申请工具页

新增页面：

- `/tools/ai-api`

新增前端模块：

- `public/ai-api-tool.js`

页面能力：

- 页面提供 curl 调用示例。

### 4. 开放 AI 对话 API

新增开放接口：

- `POST /api/open/ai-chat`

认证方式：

```http
Authorization: Bearer mmc_xxx
```

请求示例：

```json
{
  "model": "zhipu/glm-4-flash",
  "messages": [
    {
      "role": "user",
      "content": "你好，介绍一下你能做什么"
    }
  ],
  "temperature": 0.7
}
```

返回示例：

```json
{
  "ok": true,
  "reply": "AI 回复内容",
  "model": "zhipu/glm-4-flash",
  "usage": {
    "charged": false,
    "cost": "0.000",
    "todaySuccessCount": 1,
    "todayFreeLimit": 50,
    "balance": "0.000",
    "membershipActive": false,
    "pricePerCall": "0.003"
  }
}
```

重要区别：

- `/tools/ai-chat` 默认带猫猫虫仓库站内助手设定。
- `/api/open/ai-chat` 默认不带网站 AI 聊天设定。
- 开放 API 调用方如果需要 system prompt，需要自己在 `messages` 中传入。

### 5. 计费和额度规则

普通用户：

- 每天前 50 次成功调用免费。
- 超出后按 `0.003 元 / 次` 扣余额。

API 调用会员：

- 每天前 500 次成功调用免费。
- 超出后按 `0.001 元 / 次` 扣余额。
- 当前建议价格为 `6.00 元 / 30 天`。

计费规则：

- 只有 AI 正常返回内容后才算成功调用。
- 成功调用才会增加成功次数。
- 超出免费额度后的成功调用才会扣余额。
- 上游 AI 服务失败不计成功次数，不扣余额。
- 参数错误不计成功次数，不扣余额。
- 余额不足不计成功次数，不扣余额。
- 上下文过长导致失败不计成功次数，不扣余额。
